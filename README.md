# design-to-web

피그마 링크, JPG 시안, 다른 사람이 만든 HTML을 웹 페이지(HTML · SCSS · jQuery)로 만들어 주는 Claude 스킬의 **최신 규칙**이 있는 곳입니다.

팀원은 Claude에 스킬(`figma-to-web`)을 한 번만 설치하면 됩니다. 스킬은 실행할 때마다 이 저장소의 최신 규칙을 받아 와서 그대로 따릅니다.

## 쓰는 법 (팀원)

1. 받은 `figma-to-web.zip`을 Claude 설정의 스킬 메뉴에서 올립니다. (처음 한 번)
2. Claude 설정에서 코드 실행 기능이 켜져 있어야 합니다.
3. 새 대화에서 피그마 링크나 시안 파일을 주고 이렇게 말합니다.
   - 기획: "이 피그마 미리보기로 만들어줘"
   - 디자인: "이 시안 웹에서 어떻게 보이는지 보여줘"
   - 개발: "이 피그마 퍼블리싱해줘"

## 고치는 법 (관리자)

- 규칙: `skill/references/*.md`
- 작업 순서: `skill/WORKFLOW.md`
- 스크립트: `skill/scripts/`
- 고친 뒤 `VERSION` 숫자를 올리고 `CHANGELOG.md`에 한 줄 적습니다. 다음 실행부터 모두에게 적용됩니다.
- 결과물 뼈대(`template/`)는 회사 코드라 이 저장소에 없고 설치용 스킬 안에만 있습니다. 뼈대를 바꾸면 설치용 zip을 다시 배포해야 합니다.

## 넣지 않는 것

비밀번호, API 키, `.env`, `auth.json`, 회사 내부 코드는 이 저장소에 올리지 않습니다. 공개 저장소입니다.
