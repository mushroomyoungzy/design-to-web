# 마크업·시맨틱·접근성·JS 규칙

## 이름 짓기

| 종류 | 형태 | 예 |
|---|---|---|
| id | snake_case. JS가 잡는 요소가 하나일 때 | `#main_visual`, `#btn_top` |
| 스타일 클래스 | BEM | `.business__slide`, `.news-item__title` |
| JS·모션 훅 | `__` 접두. 스타일 금지. 잡는 요소가 여러 개일 때 | `.__open-toggle`, `.__slide` |

- id가 이미 있으면 같은 요소에 훅 클래스를 또 붙이지 않는다
- 훅 클래스는 실제로 JS에서 쓰는지 확인한다
- 상태 클래스: `on`, `open`, `show`, `active`, `is-*`
- 페이지 전체를 `<div id="<id>">` 하나로 감싼다. id는 작업마다 정한다 (예: `hepi_main`)

## 문서 구조

```
#wrap.wrap
└ div#<id>
   ├ header (디자인에 있으면)
   ├ main
   │  ├ h1.sr-only (사이트 이름)
   │  └ section …
   └ footer (디자인에 있으면)
```

- 섹션은 `<section>`, 섹션마다 제목이 있다
- 섹션 주석: `<!-- Name -->` … `<!--// Name -->`
- 형제 섹션 사이에 빈 줄 한 줄

## 제목 단계

- 메인 비주얼·서브 비주얼 제목이 `h2`. **본문 섹션 제목은 `h3`부터**, 그 아래 카드·항목 제목은 `h4`, `h5`
- 시각적 크기가 아니라 구조로 정한다

## 줄바꿈

문장 중간 `<br>` 앞에는 띄어쓰기를 하나 넣는다 (분기점에서 `<br>`을 숨기면 단어가 붙지 않게). 예: `고객의 공정에 적합한 <br>접착 솔루션을`

## 마크업 순서 (스크린리더·Tab 순서)

- 더 보기·바로가기·자세히 보기 버튼, 슬라이드 컨트롤(이전/다음, 페이지 번호, 진행바)은 **콘텐츠보다 뒤에** 마크업한다
- 마크업 순서: [제목·설명 → 콘텐츠 → 버튼 → 컨트롤]
- 시안에서 버튼이 제목 옆·위에 있어도 화면 위치는 **`grid-template-areas`** 로 잡는다. `order`나 `position: absolute`로 옮기지 않는다
- 1열로 쌓이는 구간에서는 화면 순서도 마크업 순서를 따라 버튼을 맨 아래로 내리고 가운데 정렬한다
- 게시판 '더보기'처럼 작은 링크는 아래로 내리면 눈에 안 띄므로 모든 폭에서 제목 옆에 둔다 (마크업은 여전히 목록 뒤)

## 접근성

- 장식 아이콘: `aria-hidden="true"`
- 아이콘만 있는 버튼: `<span class="sr-only">이전 슬라이드</span>` 같은 문구. aria-label을 써도 괜찮은 곳이면 aria-label 가능
- 새 창 링크: `target="_blank"` + sr-only "(새 창에서 열림)"
- 버튼은 `<button type="button">`, 이동은 `<a>`
- 탭 UI: `role="tablist"`, `role="tab"`, `aria-selected`, `aria-controls`

## 연락처 링크

- 전화번호·휴대폰·팩스가 아닌 번호(대표전화, 상담전화, 1588 번호 등)는 화면 어디에 있든 **반드시** `<a href="tel:02-1234-5678">02-1234-5678</a>`로 감싼다. 헤더·푸터·오시는 길·카드 속 번호까지 빠짐없이
- 이메일은 `<a href="mailto:help@example.com">help@example.com</a>`
- 카카오톡 채널·SNS 주소처럼 이동할 곳이 있는 것도 `<a>`로 둔다 (주소를 모르면 `href="#"`)
- 글자 모양은 주변 글과 같게 둔다 (`a`는 `color: inherit`). 아이콘만 있는 전화 버튼은 sr-only로 번호를 적는다
- 사업자등록번호처럼 연결할 곳이 없는 번호는 링크하지 않는다

## 이미지

- 이미지 자리마다 빠짐없이 `<img>`를 넣는다. **배경 이미지도 CSS `background`가 아니라 `<img>`** (CMS에서 경로만 바꿔 쓰기 위해). 예외: 지도 API 영역, aria-hidden 장식 그래픽
- 경로: `assets/images/<id>/파일명`. 파일명은 용도가 드러나게 (`main-visual-01.jpg`, `business-slide-03.jpg`)
- 디자인에 이미지가 비어 있는 자리는 `src` 없는 빈 `<img>`
- alt는 이미지의 용도. 사람 사진은 이름 포함, 장식 배경은 `alt=""`
- 아이콘: boxicons `<i class="bx bx-chevron-right" aria-hidden="true"></i>` 기본. 디자인 고유 아이콘·로고는 SVG 파일로

## 카피

- 디자인에 없는 카피는 **비워 두고 묻는다.** 다른 페이지의 비슷한 문구를 가져오지 않는다
- 자리표시자 문구("제목이 표시됩니다")는 그대로 둔다

## JS

- jQuery로 쓴다. 요소 선택·이벤트·클래스 토글 모두 `$()`
- 별도 파일 없이 `index.html` 맨 아래 인라인 `<script>`에 쓴다
- 변수는 카멜케이스, 문자열은 홑따옴표
- Swiper·GSAP 등 DOM 요소를 직접 받는 라이브러리에는 `$el[0]`로 넘긴다
- 탭 필터, 더보기, 문의 등 기능은 더미로 동작만 보여준다

## 파일 편집

- 파일은 **처음 만들 때 한 번만** 통째로 쓴다. 그 뒤로는 한 줄 수정이라도 부분 치환. 사용자가 그 사이에 값을 고쳐 뒀을 수 있다
- 편집 직전에 해당 부분을 다시 읽고 실제로 있는 문자열만 치환한다. 치환이 안 되면 멈추고 묻는다
- 반복 카드도 생성 스크립트로 파일을 찍어내지 않는다
